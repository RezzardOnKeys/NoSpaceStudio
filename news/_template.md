Copy this file, give the copy a name like `2026-01-31-my-post.md` (no leading
underscore) and write the post here in **Markdown**.

Allowed values for `type`: `announcement`, `launcher_update`, `game_update`.
A `game_update` also needs the game's folder name and usually a version:

```
type: game_update
game: my-game
version: 1.2.0
```
